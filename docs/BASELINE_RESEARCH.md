# Global Dual Momentum 第一版研究说明

## 本轮问题

本轮不回答“策略能否赚到钱”，只验证以下最小研究闭环是否成立：价格宽表可以进入系统，月末双动量逻辑能生成无前视目标，VectorBT 能执行并报告指标，相同排名规则能由 RQAlpha 月度 callback 表达。

## 数据与方法

默认 smoke test 使用 `research/experiments/run_gdm_baseline.py` 生成的确定性演示价格。这些序列人为包含不同漂移、周期和共同下跌段，不是真实市场数据，不可用于选择参数、判断收益或对外展示业绩。

真实研究入口接受复权收盘价 CSV。研究代理与生产工具不等价；ETF 上市时间、流动性、跟踪误差、QDII 溢价、税费和可交易状态仍需在正式验证前检查。

## 当前结论

- 研究管线结论：已在 2014-01-02 至 2025-12-31 的确定性演示序列上实际运行，输出 CAGR -21.2464%、最大回撤 -94.3146%、Sharpe -5.1238、Calmar -0.2253、累计单边换手 26.5、148 笔资产级交易、平均持有 100.72 天。负收益不代表真实策略结论；这些数值只证明执行、交易记录和指标路径可用。148 笔资产级交易分布在约 12 年月度调仓中，约为每月 1.03 笔。
- 策略经济结论：没有。演示数据不能提供 alpha 证据。
- RQAlpha 结论：5.6.5 adapter、月度 callback 与费用/滑点配置已建立并通过隔离行为测试；实际检查明确报错 `RQAlpha bundle 目录不存在`，因为本机 `/home/jcshi/.rqalpha` 不存在。完整事件驱动结果当前不得声称已跑通。

下一项研究只能在可靠真实数据上进行参数平台、walk-forward、样本外、市场状态与成本敏感性分析。
