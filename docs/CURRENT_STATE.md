# 当前状态

## 一句话结论

S1 全球双动量已完成证据闭环，最终决策为 **REJECT_S1**：冻结基线在 2013-06-28 至 2026-08-31 的 CAGR 为 8.32%，但最大回撤为 -46.81%，未能在四组同区间比较中同时胜过简单基准的 CAGR、Sharpe 和最大回撤，2020–2022 为负，滚动窗口也出现负收益；RQAlpha 官方 bundle 实跑进一步显示当前目标权重在真实市场执行约束下明显失真。

- RQAlpha 5.6.5 官方 bundle 的事件驱动差异验证；
- 标的上市可用性和有边界的选择偏差审计。

## S1 主要证据

### 基线与时间稳定性

| 指标 | 结果 |
| --- | ---: |
| CAGR | 8.32% |
| 最大回撤 | -46.81% |
| Sharpe | 0.491 |
| Calmar | 0.178 |
| 累计单边换手 | 38.00 |

| 子区间 | CAGR | 最大回撤 | Sharpe |
| --- | ---: | ---: | ---: |
| 2013–2016 | 7.45% | -46.81% | 0.405 |
| 2017–2019 | 8.38% | -21.27% | 0.649 |
| 2020–2022 | -0.78% | -35.32% | 0.052 |
| 2023–2026 伪样本外 | 18.65% | -18.99% | 0.939 |

滚动 3 年 CAGR 最低 -10.94%，滚动 5 年 CAGR 最低 -2.73%。2023–2026 表现良好，但它是已经查看过的 chronological holdout，不是真正未触碰样本外，不能覆盖完整历史的脆弱性。

### 简单基准

- 沪深300买入持有同区间 CAGR 7.61%，最大回撤 -45.45%；S1 收益略高但回撤略差；
- 标普500 ETF 自上市后 CAGR 14.39%、最大回撤 -29.67%，明显优于同区间 S1；
- 九只当前风险资产全部上市后的年度等权 CAGR 11.35%、最大回撤 -20.52%，优于同区间 S1；
- 季度股债金 60/20/20 CAGR 7.99%、最大回撤 -29.61%，S1 仅多约 0.5 个百分点 CAGR，却承担显著更大回撤。

基准按真实上市可用区间开始，没有回填不存在的 ETF 历史。年度等权与股债金使用 VectorBT 原生目标订单和实际订单记录计算换手。

### 成本与回撤

总单边成本从 5、15、30 到 50 bps 时，CAGR 从 8.95% 依次降至 8.32%、7.37% 和 6.12%；高成本没有完全抹去正收益，但回撤始终约 -47%。

最大回撤由 VectorBT drawdown record 定位：2015-06-12 见顶，2016-01-28 到谷底，2024-01-22 才恢复。组合在下跌阶段持续 50/50 持有沪深300和中证500；两者同期均大跌且高度相关，没有转入防御资产。证据支持集中风险、动量滞后、相关资产共同下跌和防御缺席，而不是数据或自研执行伪影。

Partial Top-K 的实际行为也已确认：只有一只风险资产正动量时，会把 100% 配给该资产。它在 159 个月末信号中发生 7 次（4.40%），但没有一次位于最大回撤起点至谷底，因此不是足以单独支持 `REVISE_S1` 的主导解释。

## RQAlpha 验证状态

已实际执行：

```text
rqalpha version                    → 5.6.5
rqalpha download-bundle            → 成功，bundle 位于仓库外 ~/.rqalpha/bundle
RQAlpha S1 2013-07-01..2026-08-31 → 成功
```

适配器修复了对未来才上市 ETF 请求历史数据的问题，并通过 instrument 的 `listing_at` 过滤；`history_bars` 显式使用 `adjust_type="pre"`。前复权和 Tushare 后复权在同一个收益比率窗口中经济等价，不需要自研复权。

158 次月度目标中，RQAlpha 与 VectorBT 有 137 次完全一致（86.71%）；其余差异来自两个供应商的历史价格/缺失观测口径及 RQAlpha 跳过停牌 bar 的语义。RQAlpha 累计收益 100.37%、最大回撤 -45.77%、换手 37.46、成交 283 笔、交易成本 75,245.76；VectorBT 同区间累计收益 186.91%、换手 38.00。持仓差异还来自 RQAlpha 的整手、现金、费用、涨跌停和默认成交量上限：100% 目标可能因没有预留费用而撤单，低流动性 ETF 可能部分成交。这是当前信号与执行表达的实质缺陷，不是 bundle 阻塞，也不应通过自研撮合掩盖。适配器使用稳定的标的顺序并先卖后买；连续两次完整实跑的研究产物哈希一致。

## Universe 偏差状态

状态仍为 **BIAS_NOT_FULLY_RESOLVED**。年末具备 252 日动量的风险资产数从 2013 年的 2 只、2015 年的 7 只增长到 2021 年后的 9 只。日本和有色 ETF 到 2019 年才上市；当前 universe 是用今天仍存在的代理回看历史，存在幸存者和事后选择偏差。本轮没有建立 PIT ETF 数据库，也不声称解决了偏差。
