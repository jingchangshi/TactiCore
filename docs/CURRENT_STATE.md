# 当前状态

## 一句话结论

TactiCore 已建立 Tushare Pro 真实数据闭环，并在 12 个多资产 ETF 研究代理上完成全球双动量基线及四点回看期预检：252 日基线历史 CAGR 为 8.32%，但最大回撤达到 -46.81%，因此当前证据只支持继续验证 S1，不支持生产使用；RQAlpha 权威事件驱动结果仍被仓库外中国市场数据包阻塞。

## 已完成能力

### M0–M2 最小研究闭环

- Python 3.10–3.12 项目，VectorBT 和 RQAlpha 分别承担探索与权威验证职责；
- 12 个人民币交易的中国上市 ETF 研究代理，覆盖中国、美国、香港、日本/欧洲股票、黄金、商品、债券与现金；
- 252 个交易日绝对/相对动量、前 2 名等权、国债 ETF 防御和月频执行；
- 月末收盘产生信号，下一交易日执行，避免同价生成并执行信号。

### Tushare Pro 数据闭环

- `tacticore.data.tushare` 下载 `fund_daily`、`fund_adj`、`trade_cal` 和 `fund_basic`；
- `config/universe.csv` 同时记录策略、Tushare 与 RQAlpha 三套代码映射；
- canonical 价格采用“原始收盘价 × 同日基金复权因子”的后复权口径；
- 固定请求区间为 2012-01-01 至 2026-08-31，实际价格区间为 2012-05-28 至 2026-08-31；
- 数据集包含 3,467 个交易日和 12 个标的，价格与交易日历均由 SHA-256 冻结；
- 每个标的都记录来源、请求参数、复权类型、数据时间、下载时间和基金元数据。

主要产物：

```text

data/canonical/trading_calendar.csv
data/canonical/provenance.json
research/results/gdm_baseline_metrics.json
research/results/gdm_lookback_sweep.csv

```

## 数据质量证据

- 价格日期唯一且严格递增；
- 所有有效价格和复权因子均大于零；
- 行情日期全部属于对应交易所的交易日；
- 日线与复权因子按标的、日期一对一合并；
- 12 个配置上市日期均与 Tushare `fund_basic` 一致；
- 没有重复日线或重复复权因子；
- 上市后区间共发现 6 个交易日无行情，保持为缺失值，不前向填充、不猜测、不置零；
- token 仅从环境变量读取，没有写入仓库或来源清单。

复权语义仍需谨慎解释：Tushare 官方将 `fund_adj` 定义为计算基金复权行情的因子；当前研究采用后复权乘法，并将因子变化解释为分红再投资。选择后复权是为了避免前复权因查询截止日变化而整体重缩放历史价格，但供应商修订因子的风险仍然存在。

## 全球双动量真实历史结果

统一指标区间为 2013-06-28 至 2026-08-31，首笔执行日为 2013-07-01。指标从首笔执行前一个交易日的组合价值开始，以包含首笔费用和滑点，并排除 252 日预热期的空仓时间。

252 日基线结果：

| 指标 | 结果 |
| --- | ---: |
| CAGR | 8.32% |
| 最大回撤 | -46.81% |
| Sharpe | 0.491 |
| Calmar | 0.178 |
| 累计单边换手 | 38.00 |
| 资产级交易次数 | 193 |
| 平均持有期 | 124.06 天 |

四点回看期预检：

| 回看期 | CAGR | 最大回撤 | Sharpe | Calmar | 累计单边换手 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 80 | 7.98% | -44.16% | 0.483 | 0.181 | 67.50 |
| 120 | 6.76% | -48.99% | 0.424 | 0.138 | 59.50 |
| 160 | 7.88% | -45.17% | 0.477 | 0.174 | 49.00 |
| 252 | 8.32% | -46.81% | 0.491 | 0.178 | 38.00 |

四个回看期的 CAGR 均为正，未出现只有一个参数点有效的现象；但所有最大回撤都较高。该比较只是稳定性准备，不构成参数优化，也不能替代滚动前推和样本外检验。

## RQAlpha 状态

数据映射、共享策略映射和 `run_rqalpha(...)` 验证接口均已准备：

- Tushare `.SH/.SZ` → 策略 `.SS/.SZ` → RQAlpha `.XSHG/.XSHE` 显式映射；
- RQAlpha 每月第一个交易日读取不包含当日的 253 根历史日线；
- 排名与目标权重复用 `select_assets`；
- 订单、现金、费用、滑点和市场规则交给 RQAlpha。

## 改了什么

增加单一 Tushare 数据适配器、真实 canonical 数据快照、质量检查、来源清单、四点回看期研究脚本和真实研究产物；同时修正 3 个与 Tushare 元数据不一致的 ETF 上市日期，并修正 VectorBT 指标把预热空仓期计入 CAGR、遗漏首笔交易成本的口径问题。

## 为什么修改

上一状态只能证明研究管线能够在演示数据上运行，无法回答策略是否具有历史经济证据。本轮最小变更直接解除真实数据阻塞，并让不同回看期在同一评价区间可比。

## 策略影响

系统首次获得 S1 的真实历史结果。结果显示策略有正长期收益证据和一定参数邻域稳定性，但约 47% 的最大回撤、较低的 Sharpe/Calmar 以及未完成的样本外检验意味着策略仍不能进入生产候选。

## 数据影响

数据源从未落地的 Yahoo Finance 设想切换为已验证可访问的 Tushare Pro。数据层只增加 S1 所需的四个接口，没有建立通用数据平台。canonical 快照可通过固定命令重建，并可用哈希检查是否发生变化。

## 剩余不确定性

- 当前 ETF 标的池存在幸存者偏差、上市时间差异和事后选择偏差；
- QDII ETF 场内价格包含汇率、时区、溢折价、额度与跟踪误差影响；
- 6 个缺失行情尚未逐笔区分停牌和源数据缺口；
- Tushare 复权因子可能被供应商修订；
- 尚未完成滚动前推、样本外、市场状态和交易成本敏感性；
- RQAlpha 数据包缺失，事件驱动验证尚未运行。

- 是否增加研究能力：是，首次形成可冻结、可复现的真实市场证据。

TactiCore 仍然是策略优先，没有重建 DailyETF。

## 下一项唯一推荐方向

在现有 S1 和冻结数据上完成滚动前推、样本外及交易成本敏感性验证。原因是当前最重要的不确定性已从“有没有真实数据”转变为“8.32% 的历史 CAGR 和约 -46.81% 的回撤能否跨时期、跨成本假设保持”；在回答之前，不应增加 S2、S3 或新基础设施。
