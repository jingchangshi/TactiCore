# 当前状态

## 一句话结论

S2 多资产趋势跟踪的 200 日均线透明基线已完成经济筛选，最终决策为 **REJECT_S2**。它把 S1 同区间最大回撤从 -46.81% 降到 -26.18%，Sharpe 从 0.487 提高到 0.726，且滚动表现稳定；但 2015 年关键改善被 510500.SS 缺失行情造成的长期不可用严重混杂，实际执行又几乎每月需要处理约 6 个标的，不符合个人投资者的低维护目标。

S1 继续保持 `REJECT_S1`，历史产物没有改写。

## S2 是什么

S1 会在正动量资产中横向排名并集中选择前两名；S2 不比较资产强弱，而是给每只当期有完整历史的风险资产一个等额 sleeve：

```text
月末价格 > 自身 200 日简单移动平均
→ sleeve 持有该风险资产

月末价格 <= 自身 200 日简单移动平均
→ sleeve 转入 511010.SS 国债 ETF
```

没有足够历史或窗口内存在缺失行情的资产属于“不可用”，不当作负趋势，也不获得 sleeve。月末收盘产生信号，下一交易日执行；没有排名、Top-K、波动率配置、杠杆或参数搜索。

选择这个基线是为了只检验一个经济假设：独立的中长期趋势过滤能否减少 S1 在相关赢家共同反转时的集中回撤。

## 实现内容

- `config/strategy.toml` 增加冻结的 `[multi_asset_trend]` 配置；
- `tacticore.strategies.multi_asset_trend` 只计算趋势、合格状态、sleeve 目标和下一交易日权重；
- VectorBT 适配器抽出最小 `run_target_weights`，S1/S2 共用框架执行、费用、记账和记录；
- S1 输出回归测试证明抽取前后指标完全一致；
- 新增基准、分期、年度、滚动、成本、2015 机制、用户操作负担和 universe 偏差证据。

没有实现 RQAlpha S2，因为未通过经济筛选的策略不值得提前投入权威事件适配工作。

## 2015–2016 S1 失败机制

S1 在 2015-06-12 至 2016-01-28 收益 -46.81%，区间最大回撤 -45.54%；S2 同期收益 -9.95%，最大回撤 -11.64%，防御权重最高达到 100%。

但必须区分原因：510300.SS 到 2015-08-31 才真正跌破均线；510500.SS 因 2015-04-13/14 缺失行情，从 2015-04-30 到 2016-01-29 无法形成完整 200 日均线，因此被归为“不可用”，直到 2016-02-29 才给出可计算的负趋势。S2 的回撤改善是真实组合结果，但不能全部归因于趋势经济假设。
